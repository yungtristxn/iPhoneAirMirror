AirMirrorLite friend-test source
===============================

This source matches the FFmpeg candidate identified in BUILD.json. It includes
the transport-rotation and display-update experiment. It does not build or link
FDK AAC. Original project code/artwork is GPL-3.0-only; imported code retains its
own notices. The complete source and license materials accompany the executable.

Requirements to rebuild (not required just to run the app):
* Windows x64; Rust MSVC toolchain with Cargo (the original used Rust 1.95.0).
* Visual Studio C++ x64 build tools and Windows SDK.
* PowerShell 7, Git for Windows and 7-Zip in their default locations.
* Python 3 only for optional validation/packaging scripts.

Build from this source directory in PowerShell 7:

  New-Item -ItemType Directory -Force work/ffmpeg-deps | Out-Null
  Copy-Item vendor/ffmpeg/* work/ffmpeg-deps/
  ./scripts/Build-FFmpeg.ps1 -Fetch
  cargo build --release --locked --offline --features ffmpeg-aac,display-update-experiment
  ./scripts/Initialize-Worker.ps1 -Executable target/release/airmirror-lite.exe

Build-FFmpeg verifies the included source archive/signature and pinned hashes.
-Fetch downloads pinned build tools only when missing; it does not install them
or edit the global PATH. FFmpeg's complete unmodified source is in the included
tar.xz archive. Its configuration and build provenance are under build-info/.
Rust dependencies are vendored in vendor/rust; .cargo/config.toml redirects Cargo
there, so resolving the locked application dependencies needs no network.

Build scripts may select a newer installed SDK/MSVC version. BUILD.json records
the original toolchain. This is a source-rebuild recipe, not a claim of identical
binary hashes across toolsets or installation paths. Do not run Package.ps1 to
replace a working FDK fallback: it is the separate legacy packaging path.

Optional silent checks:
  cargo test --locked --offline --features ffmpeg-aac,display-update-experiment
  ./scripts/Test-Media.ps1 -Executable target/release/airmirror-lite.exe

Do not use --self-test or Test-Media.ps1 -Audio: those modes play sound.
The fixture generators and native-sanitizer harness targeting FDK are historical
development tools; FDK source is intentionally absent from this share archive.
